# Controlled Generation Protocol

This document defines the strict method-comparison track. It is separate from
the original-reproduction track and must never reuse an artifact generated by
the old backbone configuration.

## Backbone contract

Within each dataset, NCFM and HoP-TM use the same generator backbone:

| Dataset | NCFM generator | HoP-TM generator | Input |
|---|---|---|---|
| PathMNIST | ConvNet-D3, width 128, InstanceNorm, AvgPool | ConvNet-D3, width 128, InstanceNorm, AvgPool | 3x32x32 |
| COVID | ConvNet-D5, width 128, InstanceNorm, AvgPool | ConvNet-D5, width 128, InstanceNorm, AvgPool | 3x112x112 |
| Kvasir | ConvNet-D5, width 128, InstanceNorm, AvgPool | ConvNet-D5, width 128, InstanceNorm, AvgPool | 3x128x128 |

The current controlled NCFM configs are under `configs/ncfm/*/ipc10_full.yaml`.
The HoP configs are under `configs/hop_tm/*/ipc10_full.yaml`.

## What remains method-specific

The following are not forced to match because they define the algorithms:

- NCFM pretraining uses the released DSA + CutMix teacher procedure.
- NCFM condensation uses CF loss, `num_freqs=4096`, `sampling_net=false`,
  and 20,000 iterations.
- HoP uses its released DSA buffer and trajectory-matching distillation.
- Teacher/expert counts remain the declared method budgets and are reported
  explicitly; they must not be hidden as if they were equal.

## Evaluation contract

Both synthetic artifacts are evaluated by the same evaluator with the same
train-only statistics, test split, optimizer, schedule, seed set, and model
architecture. The controlled evaluator uses no augmentation in its primary
table. DSA evaluation is a separate sensitivity result.

The original method evaluators are still run and retained as auxiliary
reproduction evidence. They are not used for the strict cross-method claim.

## Artifact rule

Changing the generator backbone, normalization, objective, or seed creates a
new run. Old D4 COVID NCFM artifacts are retained for provenance but are
classified as `legacy/original` and cannot enter the controlled manifest.
Every controlled run must record the config SHA-256, source SHA-256, teacher
checkpoint SHA-256, synthetic SHA-256, command, and Slurm stdout/stderr.

## Claim rule

The controlled track supports a comparison of synthetic-data quality under a
fixed generator/evaluator contract. It does not by itself prove that one
paper's algorithm is universally superior. Formal NCFM defect claims still
require the Phase 1 effect rules and all artifact/evaluation gates.
